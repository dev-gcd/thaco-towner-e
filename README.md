# thaco-towner-e

Landing page THACO TOWNER E (xe tải van điện) + trang quản trị nội dung.
Khung clone từ `thaco-truck-sale-page`. Xem [AGENTS.md](./AGENTS.md) cho stack,
lệnh, kiến trúc CMS và việc còn lại.

```sh
pnpm install
pnpm dev:cms     # cửa sổ 1: lưng CMS  :8790
pnpm dev         # cửa sổ 2: trang     :3002
```
